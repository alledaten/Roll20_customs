## 사용방법
1. 세션 방 메인화면의 [설정]→[게임 설정]페이지로 들어갑니다.
2. 설정페이지의 가장 아래의 Character Sheet Template에서 드롭다운 메뉴를 [Custom]으로 변경합니다.
3. **[구 버전 무해화 처리] 체크하지 마세요**
4. [HTML Layout] 탭 부분에 html 파일 내용을 복사-붙여넣기 합니다.
5. [CSS Styling] 탭을 선택하고 css 파일 내용을 복사-붙여넣기 합니다.
6. 변경 사항을 저장합니다.

## 이용범위
* 개인적인 용도의 수정 및 사용 가능
* 레이아웃(html/css)및 리소스 변경시 재배포 및 커미션 사용가능

## 릴리즈 노트
2026.09.21. Ver 2.0 업데이트 
>### Ver 2.0 변경사항
>- 펄프 옵션 추가 : 체력, 펄프 광기의 발작, 펄프 재능
>- 반복 무기 필드 attribute명 변경 (repeating_weapons 및 공식 attribute 명)
>- spellcheck 기능 해제
>- 주문 설명 접기 기능
>- 피해 보너스/체격 계산 범위를 10d6 / +11까지 확장 (공식 시트)
>- 나이에 따른 MOV 수정 옵션 및 계산 기능 선택화 (공식 시트)
>- 현재 이성이 4/5 이하가 되면 장기적 광기 알림 (공식 시트)
> 
>### 업데이트 주의사항  
> 이번 버전에서는 일부 repeating(반복) 섹션의 구조 및 attribute가 변경되었습니다.  
> 기존 버전의 시트를 사용하던 캐릭터가 새 버전으로 변경할 경우, 해당 반복 섹션에 입력해 둔 기존 내용은 새 시트에서 표시되지 않으며 그대로 사용할 수 없습니다.
>
>### 영향을 받는 항목
> - 과학, 예술/공예, 컴퓨터 사용 등 `+Add` 버튼으로 추가한 기능
>- 전투에서 `비무장`을 제외한 `+Add` 버튼으로 추가한 무기
>- 주문, 다운타임, 조력자, 탈것 등 반복 입력 형식으로 작성된 데이터
>
> 기존 캐릭터에 중요한 내용이 입력되어 있다면 시트를 변경하기 전에 반드시 별도로 백업해 주세요.  
> 새로 생성하는 캐릭터에는 영향이 없습니다.
